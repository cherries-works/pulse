# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in a cherries.works project, **please do not open a public GitHub issue**.

Instead, report it privately through GitHub's **Security Advisories** feature.

Please include:

* A description of the vulnerability
* Steps to reproduce it
* The affected project and version
* The potential impact
* Any suggested mitigation, if available

## What happens next?

We will review the report and investigate the issue.

If the vulnerability is confirmed, we will work on a fix and coordinate disclosure where appropriate.

Please allow reasonable time for a fix before publicly disclosing the vulnerability.

## Scope

This policy applies to security vulnerabilities affecting cherries.works software and infrastructure.

For general bugs or feature requests, please use the appropriate GitHub issue template instead.
