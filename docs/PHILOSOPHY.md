# Cherries Works

The priority in my programs is not only to learn, but also to prioritize fast, and memory efficient programs.
Optimization is a lost art in the new day of programming, people use 6GB of RAM for a program, just because
they have enough RAM. But a lot of people do not, or a lot of people do not want to use this much RAM for
a single piece of technology.

## That is what I am trying to change, actively.

Optimizing my programs to work with little to no memory (<5MB of RAM), using buffers instead of allocating
memory unsafely, and writing safe code, that should not be causing any segfaults, bugs, or vulnerabilities
is one of my top priorities. Less RAM is good, but the program is suppose to be safe aswell.

Back then, the task manager (by David Plummer) in 1990 required 80kB of RAM. **80 KILOBYTES**! That sounds like
a myth to a lot of people, but it is true! By utilizing smart techniques to prevent writing files, using 
atomic keys, and rendering changes only, David Plummer managed to create one of, if not, the most memory
efficient program (that actually does what it promises) that I have ever seen. It is sad that a lot of
programs do not follow that principle.
