# Contributing to cherries.works

Thanks for wanting to contribute to cherries.works.

We try to build fast, and efficient tools for developers. Contributions are welcome, whether it is for code, documentation, bug reports, tests, or ideas.

## Before you start

* Check existing issues and pull requests.
* For larger changes, open an issue first so we can discuss the approach.
* Keep changes focused. Avoid unrelated refactors.
* Follow the existing code style.

## Development

Clone the repository:

```bash
git clone https://github.com/cherries-works/pulse
cd pulse
```

Build the project using the instructions in the repository README.

## Pull Requests

When opening a pull request:

* Explain what you changed and why.
* Keep the PR focused on one change.
* Include tests when appropriate.
* Make sure the project builds and existing tests pass.

## Issues

Bug reports should include:

* What happened
* What you expected to happen
* Steps to reproduce
* Relevant system information
* Logs or error output when applicable

Feature requests should explain the problem you're trying to solve, rather than only proposing a solution.

## Code of Conduct

Please be respectful and constructive.

We're building cherries.works together.
